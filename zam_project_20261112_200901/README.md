Zam Calculator
==============

A simple modern Windows desktop calculator built with Python Tkinter.

## Features
- Basic arithmetic: addition, subtraction, multiplication, division.
- Clear (C) and equals (=) buttons.
- Modern polished layout with custom button styling.

## Requirements
- Python 3.9 or newer.
- No external dependencies (Tkinter is included in the standard library).

## Running the Application
1. Clone or download the repository.
2. Open a terminal / command prompt.
3. Navigate to the project directory.
4. Run:

```bash
python main.py
```

The calculator window should appear.

## Customization
Feel free to edit `main.py` to change colors, fonts, or add more functionalities.
