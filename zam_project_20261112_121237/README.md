# Simple Calculator\n\nThis is a simple calculator implemented in Python.\n\nRun the calculator by executing:\n\n```\npython main.py\n```\n\nThe calculator supports addition (+), subtraction (-), multiplication (*), and division (/).\n\n## Example Usage\n\n````\n$ python main.py\nEnter first number: 5\nEnter second number: 3\nChoose operation (+, -, *, /): +\nResult: 8\n````\n\nFeel free to extend the functionality or integrate it into other projects.
